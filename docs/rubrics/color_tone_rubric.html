  • 按时间有序抽帧，保留片内时间码、镜头与场景变化；暂以2FPS为起点，关键变化不足时局部补帧。

色调处理合理性

  • 颜色处理是否保留必要层次、对象辨认与时间连续性？
  • 差异与变化是在妨碍观看，还是在帮助组织注意与表达？

色彩断层

观察：观察天空、雾、皮肤等应平滑过渡区域的条带，核对相邻时刻与原始帧。

判断：判断是否出现非场景结构造成的阶梯色带，并说明是否干扰形体或整体观看。

作用与边界：压缩预览或风格化分区不直接判为原片缺陷。

色彩基调

观察场景主要色相、明度、饱和度及大色块的整体倾向；分别指出来自照明、服装、化妆、道具或环境的可见颜色。

可能作用：建立整体氛围，连接同一场景或段落；暖金色可结合回忆语境形成温暖感。

边界：只评价输入片段，不推断整部影片基调；无法由成片确定滤镜、后期重印或调色工艺。

色彩削顶

观察：观察高饱和或极亮／极暗区域是否失去原有颜色层次与必要细节。

判断：记录受影响对象、持续时间和信息损失；区分刻意纯色与异常截断。

作用与边界：仅凭RGB截图不能证明后期通道削顶；可记录可见色彩层次丢失，不虚报源信号。

找出占比小但与整体色调形成色相、饱和度或明度差异的服装、道具及局部色块，检查其出现时刻。

可能作用：突出主体、动作或重要道具，帮助区分多人，并强调当前情境。

边界：最鲜艳的对象不一定是主体；颜色吸睛但抢走必要注意可能成为干扰。不得只因配色对比就判高。

异常偏色

观察：对照同一对象、邻近镜头、光源线索及整体基调，观察不协调的颜色变化。

判断：有可见参照且无法由场景或风格解释，才确认为异常；说明对辨认和氛围的影响。

作用与边界：不以真实肤色或中性白作为所有游戏的强制目标。

在可见人物处境、行动或事件中核对色彩强调的对象及前后变化。

可能作用：红可联系生命、热情、愤怒、暴力、死亡或权力；绿可联系生机、希望、神秘、阴森或嫉妒；黄可联系温暖、欢乐、乐观或欺骗；蓝可联系幽静、忧郁、寒冷或疏离；黑可联系稳重、压抑、悲哀；白可联系纯洁、和平或虚幻。暖冷也可能帮助传达亲近或距离。

局部调色接缝

观察：观察局部颜色边界是否贴合物体、光区或遮挡边界，随运动是否错位。

判断：区分正常材质／光源分区与无解释的局部色差、光晕或边界。

作用与边界：不从成片反推具体调色操作；说明可见不连续及其影响。

观察：检查主体、陪体和环境的颜色竞争；多人及关键道具能否区分，重点是否被无关色块抢走。

判断：区分有作用的对比与妨碍必要注意／辨认的配色；增强时须说明对谁、在何时、产生什么效果。

作用与边界：互补色不必冲突，同色也不必和谐；人物关系和情绪需额外片内证据。

整体判档思路

低：确认色彩处理或组织持续／在关键时刻妨碍必要辨认、层次或连续观看，列明对应指标与影响。

中：适用的基础处理成立，观看重点与连续性基本清楚，但未证实进一步增强效果。

高：满足中档基础，且有证据表明颜色安排有效加强注意、对象区分、环境理解、氛围或时序表达；不强制具备象征或情绪。

无法判断：原始画质、抽帧或上下文不足以判断时，记录缺少的证据，不硬选档。

不适用：当前对象或某手法不适用时单独标记；单一手法不适用不等于整条色调无法评价。

通用边界与证据

  • 观察知识嵌入既有两个评价因素及16个指标，不另增一套色彩手法计数评分。
  • 基调、重点色、贯穿色是观察角色，不是互斥档位；同一颜色可以承担多个角色。
  • 仅凭画面可见证据与时序联系解释作用；未观察到的手法不扣档。
  • 记录片段／时间范围、主体陪体环境、基调与局部色块、对应指标、观察事实、作用解释及可替代解释。
  • 涉及复现、跳变和节奏时，至少提供前后时间点原始帧；区分变化事实与意义推断。
  • 如辅助测量HSV／Lab分布、色块面积或帧间色差，注明颜色空间、区域与方法；测量值不直接转换为审美分数。
