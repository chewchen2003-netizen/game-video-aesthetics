机器按什么规则分档

先确定当前需要看懂的主体、动作和空间，再检查适用基础条件，最后检查增强。14项指标不平均、不投票，不按手法数量加分。

  • 低：至少一个适用最低必要条件被证据明确证明失败，并排除合理特写、正常遮挡、第一人称常规裁切等例外。
  • 中：适用基础条件成立，但未证明超出基本辨认的增强效果。
  • 高：继承中档基础，同时有可核查的有效注意引导、空间揭示或关系强化。需要“可见安排→具体联系→增强效果”的证据桥梁。

关键事实缺失且可能改变最终档位时才无法判断。基础明确成立而增强未证明，应判中。

计算公式与判档的关系

可见面积占比 = 可见掩码像素数 / (W×H)；测量表 center 是可见区域边界框中心 ((x₁+x₂)/(2W), (y₁+y₂)/(2H))，不是掩码质心；边距为 x₁/W、(W−x₂)/W、y₁/H、(H−y₂)/H。它们描述几何事实，没有面积或位置的美学分档阈值。

下面仅展示模型实际输入中的测量及其采用范围；accepted=true不代表所有字段都获采用。没有可靠完整主体掩码，遮挡比例不可得；单目深度不是米，不作为这三例增强的数值证明。

机器过程 ④ 事件证据：画面安排 → 观看影响

e2 · [[3.5, 10]] 秒

观察：右侧白墙与左侧岩石形成通道边界，人物沿间隙推进；靠墙长椅及前方深色建筑提供连续参照。接近转角后建筑廊架逐步显露。

作用：通道边缘把注意引向人物前方，先限定可见空间，再为绕角后的环境展开提供参照；人物未被大面积墙岩遮没。

排除例外：近侧墙岩虽占较大区域，但仍保留必要通路，不据面积判压迫；长椅无交互，不设为陪体。

e3 · [[10.5, 14.5]] 秒

观察：人物在左侧岩石与右侧廊柱栏杆之间前进；随绕角，建筑退到右缘，前方绿地展开，岩石边缘继续连接铺装路与草坡。

作用：同一近侧岩石和人物维持空间参照，使街巷出口与随后草坡可以连续对应；由侧向围合转为开阔视域，形成具体的环境揭示。

排除例外：廊柱、栏杆没有切断必要身体或道路信息；这是环境开放程度的变化，不推断逃离或情绪释放。

e4 · [[15, 19.5]] 秒

观察：较俯视画面保留人物和近侧岩石，在其上方展开水渠、沿渠石墙、横跨水渠的木桥与对岸道路。末段人物转为侧身，右侧建筑再次出现。

作用：坡地人物、水渠和对岸组成可追踪的高低与远近关系；木桥把水渠两侧联系起来，使此前出口外的空间由局部草坡深化为可理解的临水地形。

排除例外：人物缩小仍能定位，草丛没有导致持续丢失；未见跨桥、垂钓或明确凝视行为，不能将桥认作行动目标。末段转向不构成连接崩坏。

机器过程 ⑤ 规则核对 → 最终判档

适用基础条件成立：人物、动作和通路持续可读，未见明确裁切、遮挡或形体结构失败。增强来自墙岩通道到廊架出口、再到俯视水渠的前后组织：近侧岩石和人物延续空间参照，水渠、木桥与对岸随后展开，使主体所在坡地及周围通路得到逐步深化，满足有效空间揭示。

高于中档的依据是可核查的连续空间揭示，而非居中、景色漂亮或手法数量；不要求额外心理与情感叙事。没有确认的基础失败支持低档。
