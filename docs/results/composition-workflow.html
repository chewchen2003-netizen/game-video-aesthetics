构图：从视频输入到判档的完整流程

2026年11月24日更新

本轮流程与网站展示

视频与时间范围 → 有序抽帧 → 主体与阶段提取 → 分割核验 → 测量采用 → 事件证据 → 规则匹配 → 最终判档 → 人工复核。

本轮不是重新执行全部CV：分割、姿态、相对深度及原始测量复用既有缓存，VLM重新从RGB识别角色与阶段，并重新核验缓存。前期主体指定和定位含人工参与。

1. 视频输入与抽帧

处理过程：输入是同一批50条约20秒RGB游戏视频，保留源会话与片内时间。本轮2FPS基础采样，变化处补至4FPS。

网站查看：审核页左侧提供视频与实际输入序列，截图标注时间；只可引用实际提供的时刻。

2. 主体、陪体、环境与阶段提取

处理过程：VLM依据RGB识别当前观看对象，区分主体、陪体与前景／背景，按内容和观看任务变化划分阶段。

网站查看：“主体、陪体与环境提取”“阶段切分”展示角色依据、时间范围与必要信息。缓存对象名称不当作真值。

3. 分割与核验

处理过程：既有CV使用MobileSAM及YOLO分割／姿态、Depth Anything V2相对深度等辅助工具；本轮复用原始缓存。VLM将掩码QA与RGB对照，逐项接受或拒绝。

网站查看：“分割核验与测量”展示掩码QA及拒绝理由；错分漏分对应的派生值不参与判档。

4. 测量与有效性

处理过程：计算可见面积占比、边界框中心、边距及辅助颜色／相对深度等。可见掩码不是完整主体，没有可靠完整区域就不报告遮挡百分比。

网站查看：原始测量与实际提交测量分别提供JSON；接受掩码只代表所述用途可用，不代表全部数值精确。

5. 事件与时序证据

处理过程：把关键安排整理为“画面观察→实际作用→合理例外”事件，再通过前后帧说明变化。

网站查看：“事件证据链”“时序对照”提供原始截图和时间码；同一事件跨指标共用ID。

6. 逐项核对Rubric并判档

处理过程：按14项指标核对适用基础与增强条件，再综合判低／中／高。基础明确失败判低；基础成立、增强未证明判中；基础成立且增强证据充分判高。

网站查看：“14项指标如何对应规则”给出条件ID和事件ID；最终结果说明为什么不是相邻档。不平均指标、不按手法数量加分。

7. 人工复核与误判归因

处理过程：固定机器结果后由人工评价和批注，比较档位与理由。本轮已完成25题人工复核。

网站查看：隐藏机标辅助复核；批注本地保存并可导出。本次发布保留人工批注快照与56%一致率报告。

本轮规则与待修订意见

本轮实际运行Rubric v2.3.0。人工复核提出普通移动的空间揭示被过度加分、抽帧中的短暂裁切被过严扣档；这些意见尚未写入新版本，不反改本轮规则和结果。
