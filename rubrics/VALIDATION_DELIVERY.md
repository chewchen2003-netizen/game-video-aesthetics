# 本轮50条验证交付要求

本轮使用同一批R01–R50、冻结的构图Rubric v2.2.0。后台运行目录为 `runs/composition-v22-batch50/`。机标完成前不计算人工一致率，不把旧结果或旧事后讨论当成本轮独立复核。

## 逐条记录

1. 来源与输入：样本ID、原始片段哈希、原会话起点、4FPS抽帧及片内／原会话时间；模型实际看到的序列图、较大参考帧与覆盖图，文件尺寸及哈希。明确原始帧与实际模型输入分辨率的区别。
2. 内容提取：按阶段记录主体、陪体、环境（前景／背景）、对象ID与定位依据；保留角色不确定性。区分对象切换与同一对象的移动。
3. 分割：模型及配置、定位提示、mask、覆盖图；逐项采用／拒绝记录。定位框不是像素分割，不可靠mask的派生数值不能用于判档。
4. 测量：公式、单位、实际数值、有效性与缺失项；完整原始测量保存。另存真正送入VLM的精简测量，不把省略的数据写成模型已见证据。不将工程诊断阈值当美学分档阈值。
5. 时序：前后阶段及证据帧、可见安排变化／维持、对空间理解、观看重点及表达的作用；不把普通正反打自动算作情感增强。
6. 判断：冻结Rubric版本及哈希、请求模型及可获得实际模型信息、完整Prompt／输出结构、原始响应；每个检查点的状态、时间码、证据ID、例外检查和简洁理由。最终档位说明命中哪些整体条件，以及为何不取相邻档位。
7. 运行：实际耗时、可获得用量、失败与重试。结构校验通过不代表判档已获得人工验证。

## 独立人工复核及一致率

先固定机标结果，再提供单独人工复核入口。该入口只给视频、时间码、冻结标准和人工填写项，不展示本轮机标档位、理由或分割采用结论；人工记录独立保存，不覆盖预测。用户已看过旧结果或讨论过的样本保留熟悉度说明，不能宣称所有样本此前完全未见。

人工完成后再合并对照：报告样本数、总体一致率、三档混淆矩阵，以及无法判断／不适用的数量和处理口径。若另报双方均可判三档时的一致率，必须标明分母和排除数，不能隐去状态分歧。典型误判从用户复核中整理，附机标、人工意见、时间码截图及原因；不能仅凭一次分歧就证明某一方正确。

原50条旧版结果可在新预测固定后做前后对照，绝不加入新机标输入。三条试跑的事后评论也不计入本轮独立一致率。

## 其他维度：先交代方法，不要求全量运行

每个其余维度至少说明：

- 输入：视频／RGB帧／音频及所需上下文，采样方式、分辨率、时序与音画同步；所选模型实际是否支持相应模态。
- 判断或计算：评价因素及观察指标、所需模型／程序、计算步骤、必要的Rubric或Prompt、输出与证据不足处理；未实现部分明确列为方案。
- 验证：小规模、覆盖不同表现的样本设计；独立人工复核标准、统计口径、边界／反例和典型误判检查。未运行不得填实测结论。

Rubric是判断标准，不替代输入设计、计算步骤和验证方案。其他维度暂不必展开到构图本轮相同的完整执行规模。
